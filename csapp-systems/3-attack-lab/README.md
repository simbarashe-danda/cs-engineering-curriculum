# CS:APP Attack Lab

This directory contains materials, exploit code, and analysis for the CS:APP Attack Lab.

## Files

*   **`instruction_encodings.md`**  
    Reference tables for x86-64 instruction byte encodings.
*   **`phase*_analysis.md`**  
    Detailed reverse engineering and exploit construction notes for phases 1 through 5.
*   **`phase*_exploit_code.s`**  
    Assembly source code for the injected shellcode payloads.
*   **`rop_gadget_farm.s`**  
    Extracted usable ROP gadgets from the `rtarget` binary.
*   **`target_disassembly_annotated.s`**  
    Disassembly file used to analyze the target binaries.
