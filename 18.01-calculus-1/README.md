# 18.01 — Single Variable Calculus

Problem sets and derivations following MIT 18.01SC OCW (Jerison).

https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/

## Structure

| Module | Content |
|--------|---------|
| 1-differentiation | Limits, derivatives, optimization, implicit differentiation |
| 2-integration | Fundamental theorem, Riemann sums, integration techniques |
| 3-series-approximations | Taylor series, asymptotic behavior |
