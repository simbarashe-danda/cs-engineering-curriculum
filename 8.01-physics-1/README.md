# 8.01 — Classical Mechanics

Problem sets and derivations following MIT 8.01 OCW (Lewin, 1999)
and Ohanian, *Physics, 2nd Edition* (W.W. Norton, 1989).

MIT 8.01 OCW:
https://ocw.mit.edu/courses/8-01-physics-i-classical-mechanics-fall-1999/

## Structure

| Module | Content |
|--------|---------|
| 1-kinematics-dynamics | Newtonian mechanics, reference frames, force analysis |
| 2-conservation-laws | Work, energy, linear momentum |
| 3-rotational-mechanics | Torque, angular momentum, rigid body dynamics |

## Methodology

Ohanian chapter read first for mathematical derivation and problem
sets. Lewin lecture watched after for physical intuition and
demonstration. All problems worked from first principles with
full unit analysis at every step.
