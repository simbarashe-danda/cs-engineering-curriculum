# 8.01 — Classical Mechanics

Problem sets and derivations following
MIT 8.01 OCW (Lewin, 1999) and Ohanian,
*Physics, 2nd Edition*.

## Structure

| Module | Content |
|--------|---------|
| 1-kinematics-dynamics | Newtonian mechanics, reference frames, force analysis |
| 2-conservation-laws | Work, energy, linear momentum |
| 3-rotational-mechanics | Torque, angular momentum, rigid body dynamics |

## Methodology

Ohanian chapter first for mathematical derivation.
Lewin lecture after for physical intuition.
All problems worked from first principles with full unit analysis.
