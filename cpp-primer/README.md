# C++ Primer

Exercises and implementations from
*C++ Primer, 5th Edition*, Lippman, Lajoie & Moo,
Addison-Wesley, 2012.

## Structure

| Module | Content |
|--------|---------|
| core-fundamentals | Basic types, expressions, statements, functions, I/O library |
| object-oriented | Classes, inheritance, polymorphism, virtual dispatch |
| memory-management | RAII, smart pointers, dynamic allocation |
| stl-structures | Generic programming, iterators, containers |

## Note

C++ studied as a secondary track alongside CS:APP and K&R.
Emphasis on understanding what C++ abstracts over C,
informed by CS:APP systems knowledge.
