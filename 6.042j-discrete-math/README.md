# 6.042J — Mathematics for Computer Science

Proof work and problem sets following MIT 6.042J,
*Mathematics for Computer Science*, Leighton & Meyer, 2010.

Course materials available via MIT OpenCourseWare (OCW):
https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-fall-2010/

## Structure

| Module | Content |
|--------|---------|
| 1-proofs | Induction, number theory, proof techniques |
| 2-structures | Graph theory, relations, partial orders, state machines |
| 3-counting | Sums, asymptotics, recurrences, counting rules |
| 4-probability-theory | Random variables, expectation, deviation bounds, random walks |

## Proof Standards

Every proof states technique upfront and includes:
- Base case explicitly verified
- Inductive hypothesis clearly scoped
- Inductive step using only the stated hypothesis
- All cases exhausted with no gaps
