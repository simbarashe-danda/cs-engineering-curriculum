## Standards

**Correctness:** Every non-trivial algorithm includes a stated
invariant and complexity justification under the RAM model.

**Systems verification:** C code validated with `valgrind`,
`gcc -Wall -Wextra -Werror`, and `gdb` under WSL2/Ubuntu.

**Proof discipline:** Proofs constructed from first principles —
base case, inductive hypothesis, and inductive step stated
explicitly. No hand-waving.
